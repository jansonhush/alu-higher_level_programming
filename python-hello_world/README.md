# Python - Hello, World

These are the small scripts I wrote while learning the basics of Python: printing, f-strings, string slicing, and running Python from the shell.

## What's inside

- `0-run`: shell script that runs the Python file named in `$PYFILE`
- `1-run_inline`: shell script that runs the Python code stored in `$PYCODE`
- `2-print.py`: prints a sentence
- `3-print_number.py`: prints a number using an f-string
- `4-print_float.py`: prints a float rounded to 2 digits
- `5-print_string.py`: prints a string 3 times, then its first 9 characters
- `6-concat.py`: joins two strings into one sentence
- `7-edges.py`: grabs the first 3, last 2 and middle letters of a word
- `8-concat_edges.py`: builds a new sentence out of slices of a string
- `9-easter_egg.py`: prints the Zen of Python

## How to run

Make a script executable, then run it:

```bash
chmod u+x 2-print.py
./2-print.py
```
