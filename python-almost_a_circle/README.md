# Python - Almost a circle

This project covers OOP, inheritance, getters/setters, `*args`/`**kwargs`, JSON serialization/deserialization, and unit testing in Python.

## Structure

* `models/__init__.py`: Initializes the `models` package.
* `models/base.py`: Defines the `Base` class for ID management and JSON file operations.
* `models/rectangle.py`: Defines the `Rectangle` class inheriting from `Base`.
* `models/square.py`: Defines the `Square` class inheriting from `Rectangle`.
* `tests/`: Contains unit tests for all classes and methods.
