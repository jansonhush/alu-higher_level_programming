# Python - if/else, loops, functions

These are the scripts I wrote while learning conditions, loops and functions in Python.

## What's inside

- `0-positive_or_negative.py`: prints whether a random number is positive, zero or negative
- `1-last_digit.py`: prints the last digit of a random number and compares it to 5 and 0
- `2-print_alphabet.py`: prints the lowercase alphabet without a new line
- `3-print_alphabt.py`: prints the lowercase alphabet except `q` and `e`
- `4-print_hexa.py`: prints the numbers 0 to 98 in decimal and hexadecimal
- `5-print_comb2.py`: prints the numbers 00 to 99 separated by `, `
- `6-print_comb3.py`: prints every combination of two different digits
- `7-islower.py`: function that checks for a lowercase character
- `8-uppercase.py`: function that prints a string in uppercase
- `9-print_last_digit.py`: function that prints and returns the last digit of a number
- `10-add.py`: function that adds two integers
- `11-pow.py`: function that computes a to the power of b
- `12-fizzbuzz.py`: function that prints FizzBuzz from 1 to 100

## How to run

Make a script executable, then run it:

```bash
chmod u+x 0-positive_or_negative.py
./0-positive_or_negative.py
```
