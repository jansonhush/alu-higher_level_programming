# Python - Data Structures: Lists, Tuples

These are the scripts I wrote while learning about lists and tuples in Python.

## What's inside

- `0-print_list_integer.py`: prints all integers of a list, one per line
- `1-element_at.py`: safely retrieves an element from a list
- `2-replace_in_list.py`: replaces an element of a list at a given position
- `3-print_reversed_list_integer.py`: prints all integers of a list in reverse order
- `4-new_in_list.py`: replaces an element in a copy of a list
- `5-no_c.py`: removes all `c` and `C` characters from a string
- `6-print_matrix_integer.py`: prints a matrix of integers
- `7-add_tuple.py`: adds two tuples
- `8-multiple_returns.py`: returns a tuple with a string's length and first character
- `9-max_integer.py`: finds the biggest integer of a list
- `10-divisible_by_2.py`: tells which integers of a list are multiples of 2
- `11-delete_at.py`: deletes the item at a given position in a list
- `12-switch.py`: swaps the values of `a` and `b`

## How to run

Each function is meant to be imported from a main file:

```python
#!/usr/bin/python3
print_list_integer = __import__('0-print_list_integer').print_list_integer

print_list_integer([1, 2, 3])
```

`12-switch.py` can be run directly:

```bash
chmod u+x 12-switch.py
./12-switch.py
```
