# Python - Test-driven development

This directory contains Python functions and their corresponding interactive doctests and unit tests using `doctest` and `unittest`.

## Files

* `0-add_integer.py`, `tests/0-add_integer.txt`: Adds two integers or floats after casting floats to integers.
* `2-matrix_divided.py`, `tests/2-matrix_divided.txt`: Divides all elements of a matrix by a number, rounded to 2 decimal places.
* `3-say_my_name.py`, `tests/3-say_my_name.txt`: Prints `My name is <first name> <last name>`.
* `4-print_square.py`, `tests/4-print_square.txt`: Prints a square of size `size` using `#`.
* `5-text_indentation.py`, `tests/5-text_indentation.txt`: Prints text with two newlines after `.`, `?`, and `:`.
* `tests/6-max_integer_test.py`: Unittests for `max_integer(list=[])`.
