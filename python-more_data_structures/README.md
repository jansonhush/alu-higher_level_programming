# Python - More Data Structures: Set, Dictionary

These are the scripts I wrote while learning about sets, dictionaries and functional tools such as `map` in Python.

## What's inside

- `0-square_matrix_simple.py`: returns a new matrix with the square of every value
- `1-search_replace.py`: returns a new list with every occurrence of an element replaced
- `2-uniq_add.py`: adds all unique integers of a list
- `3-common_elements.py`: returns the elements present in both sets
- `4-only_diff_elements.py`: returns the elements present in only one of two sets
- `5-number_keys.py`: returns the number of keys in a dictionary
- `6-print_sorted_dictionary.py`: prints a dictionary ordered by key
- `7-update_dictionary.py`: replaces or adds a key/value in a dictionary
- `8-simple_delete.py`: deletes a key from a dictionary
- `9-multiply_by_2.py`: returns a new dictionary with all values multiplied by 2
- `10-best_score.py`: returns the key with the biggest integer value
- `11-multiply_list_map.py`: multiplies every value of a list using `map`
- `12-roman_to_int.py`: converts a Roman numeral to an integer

## How to run

Each function is meant to be imported from a main file:

```python
#!/usr/bin/python3
number_keys = __import__('5-number_keys').number_keys

print(number_keys({'a': 1, 'b': 2}))
```
